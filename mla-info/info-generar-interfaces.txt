Sí, amigo. Y para lo que tú estás pensando —un sistema documental personalizado, con usuarios, documentos, metadatos, búsquedas, trazabilidad, permisos y posiblemente conexión a SQL Server/Oracle— hay varias alternativas interesantes que puedes montar en tu propio servidor sin pagar licencias.

Yo separaría las opciones en dos grupos:

1. Constructor visual de interfaces

Estas herramientas permiten crear pantallas tipo CRUD, formularios, dashboards, búsquedas y administración, conectándose a bases de datos o APIs.

Herramienta	Licencia / modalidad	Ideal para
Appsmith	Open Source / Apache 2.0 para el core	Interfaces web internas, CRUD, dashboards, SQL y APIs
ToolJet	Open Source / AGPL-3.0	Aplicaciones internas y formularios visuales
Budibase	Open Source / GPL-3.0	Aplicaciones empresariales y formularios
NocoBase	Open Source	Sistemas orientados a datos y back-office
Refine	Open Source	Si quieres desarrollar con React pero acelerar mucho la interfaz

Appsmith, por ejemplo, permite crear interfaces visualmente, conectar bases de datos y APIs y ejecutar todo en tu propia infraestructura.

ToolJet también tiene una edición Community que puedes instalar localmente; actualmente declara licencia AGPL-3.0 para esa edición y soporte para Docker/Kubernetes/on-premise.

2. Sistemas documentales ya hechos

Aquí hay una opción que creo que te puede interesar muchísimo:

Paperless-ngx

Es un DMS/gestor documental Open Source que permite almacenar documentos, hacer OCR, buscar dentro del contenido, manejar metadatos, etiquetas, tipos documentales, etc. Tiene una interfaz web completa y se puede instalar mediante Docker.

Otra alternativa más orientada a gestión documental empresarial es:

Mayan EDMS

Está pensado específicamente como un Electronic Document Management System (EDMS) y tiene capacidades de gestión documental y flujos. Actualmente está bajo GPL-2.0.

Para tu proyecto concreto, yo partiría evaluando Appsmith + Spring Boot + PostgreSQL/SQL Server + almacenamiento de documentos, y analizaría Paperless-ngx si quieres incorporar OCR e indexación sin desarrollar todo desde cero.
